# Portfolio - Андрей Карганов

Персональный портфолио-сайт, демонстрирующий навыки и опыт работы в веб-разработке. Проект создан с использованием современных технологий и лучших практик разработки.

## 🚀 Функциональность

- **Главная страница** с приветственным блоком и списком проектов
- **Опыт работы** с подробным описанием достижений и технологий
- **Навыки** с визуализацией уровня владения технологиями
- **Образование** с информацией об учебных заведениях
- **Контактная форма** с интеграцией Telegram для получения сообщений
- **Адаптивный дизайн** для всех устройств

## 🛠 Технологии

### Backend
- **Go** - основной язык программирования
- **PostgreSQL** - база данных
- **pgx** - драйвер для работы с PostgreSQL
- **Gorilla Mux** - HTTP роутер (встроенный в стандартную библиотеку)

### Frontend
- **React 18** - библиотека для пользовательского интерфейса
- **TypeScript** - типизированный JavaScript
- **Vite** - инструмент сборки и разработки
- **React Router** - маршрутизация
- **Axios** - HTTP клиент
- **React Icons** - иконки
- **ESLint** - линтер кода

### DevOps
- **Docker** - контейнеризация (готовность к использованию)
- **Git** - система контроля версий

## 🗄 Схема базы данных

Проект использует PostgreSQL с пятью основными таблицами:

- **projects** - портфолио проекты
- **work_experience** - опыт работы
- **education** - образование
- **skills** - технические навыки
- **contact_messages** - сообщения с контактной формы

## 🔌 API Endpoints

| Метод | Endpoint | Описание |
|-------|----------|----------|
| GET | `/api/projects` | Получить список проектов |
| GET | `/api/experience` | Получить опыт работы |
| GET | `/api/education` | Получить образование |
| GET | `/api/skills` | Получить навыки |
| POST | `/api/contact` | Отправить сообщение |
